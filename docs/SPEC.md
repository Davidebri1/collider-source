# Collider — Product Spec (as given by user)

## Core concept
Mobile app (native, not web app) that queries multiple AI models at once and shows responses in a grid. Tap any card to open a standard single-model card/detail view.

## Featureset philosophy
General featureset applies across all models/tabs, consolidated from industry leaders (ChatGPT, Claude, Gemini, Grok, etc.) so users never leave the app because a competitor has a feature this one lacks (e.g. a Grok user shouldn't miss an "Imagine Market" equivalent and go back to Grok).

## Tiers & monetization
- **Free**: 20 messages/day, **general chat models only** (free-tier models). No access to image/video/audio (media gen) or coding (agentic, customizable) models at all.
- **Pro / Elite**: unlimited general chat (all tiers of general model — free/pro/elite — free of charge/no cap for paid subscribers). Daily credits for pro/elite tier models in image/video/audio/coding categories only. Elite unlocks pro AND elite models; Pro unlocks only pro (+ free). General models are accessible by all free viewers at a metered rate (20/day); paid tiers get general unlimited.
- Model roster: General has 6 free + 3 pro + 3 elite models. Video/Audio/Coding/Images each have 3 pro + 3 elite models.

## Grid / theme requirements
- Background image changeable via a theme switcher.
- Background must be uninterrupted by cards or other permanent UI — **cards must be transparent** so the background shows through, in both grid view and card detail view.
- Seamless transition from grid view to card view.
- Left drawer: History.
- Right drawer: Smart Gen tools — **global** scope when opened from grid view, **local/scoped to current model** when opened from card view.

## Smart Gen tools
A pulled-from-competitors feature set, with a twist: **autogenerated from detailed context extraction** during conversation. Example: walk through a legal case across chat (facts, questions) — Smart Gen should:
- Auto-create a **Project** for the case if one doesn't already exist.
- Extract deadlines mentioned in conversation, look them up if needed, present as **Reminders** — and reminders with a date/time automatically add to a full-featured **Calendar** (Google Calendar-equivalent functionality), with filters by model/project/other key fields.
- Auto-generate **Artifacts** (e.g. a timeline, a statement) as documents, saved into the relevant Project automatically.
- **No duplicates** within a category/project/model (dedup).
- Items are **freely convertible** between types (Memory ↔ Reminder ↔ Artifact ↔ Project, etc.) and support **custom fields**.
- Items can be **embedded/attached** in one another: artifacts auto-attach to files/reminders/tasks/projects; reminders auto-attach to projects/artifacts/memories; etc.

Five Smart Gen types: **Projects, Tasks, Reminders (+ Calendar), Memories, Artifacts.**

## Search
Global search with filters for type (conversation history, smart gen tool type, etc.) and by model.

## Consensus feature
Full-screen drawer, opened from chat. Layout top to bottom:
1. Number of selected models that agree, at the top, **colored red→green based on alignment**.
2. Below that: a brief consensus summary in **soft glowing blue text**.
3. Below that: the **dissenting map** — a 2.5D/3D "galactic" constellation of dissenting views on a **black background**, styled like stars in a galaxy.
   - Each dissenting model = a glowing 3D/2.5D sphere with a one-line dissent summary, model name shown abbreviated next to the sphere.
   - Consensus summary is centered horizontally with space left/right.
   - Dissenting spheres positioned **vertically** by how much they agree with the consensus summary (closer = more aligned).
   - Positioned **horizontally** by their collective agreement with *other* dissenting views — this is a **net force calculation**: models in strong mutual disagreement end up on opposite horizontal ends; models with strong affinity to each other cluster together, and that affinity can pull them (and by extension, the group) closer to center.

## Purpose statement
Bring practical functionality — validate models against each other, get productive outputs, continue conversations (competitors can't). Not offered anywhere else currently.

## Media gen / credits
- Media gen models (image/video/audio) require credits, accessible to Pro and Elite tiers.
- Credits: daily and monthly limits (possibly weekly too).
- Pro/Elite get **unlimited** use of general (chat-only) tabs; free users get general at a metered daily rate.
- Full Grok Imagine Market equivalent required — not a partial version.

## Visual bar ("gold standard" / "smart TV level quality")
Explicitly mandatory, not optional: depth, layered UI, shadows, 3D where warranted, blur, depth-of-field, gradients, textures, brushed metal, sheen, glass, subtle reflections (pond-like). Establish a new AAA/premium/immersive mobile-app visual standard — "not a mystery to solve."

## Build approach note (user's own reasoning, resolved)
User asked whether to build on the existing app or start fresh, noting many imports/integrations could shortcut the work (Figma for UI, Google Calendar/Tasks direct import for the calendar, Gemini suite covering "90%" of the app). **Resolved: build on the existing app** — it already scaffolds most of this spec (grid, card view, history/memory/reminders/projects/files/market/wallpapers/upgrade screens, IAP, Groq/OpenRouter chat). See `docs/AUDIT.md` for the detailed gap analysis against this spec and `docs/PROGRESS.md` for what's been done since.

## Testing constraint (important, ongoing)
User has **no physical device and no paid Apple developer account** — the only viable test path is `expo start --web` in a browser. All work must function correctly on **both web and native** without needing a manual swap-out step between test and ship builds.
